# RELEASE_NOTES.md

## Релиз 0.3.1

Дата: 2026-06-10

## Что изменилось

Backend заявок больше не отправляет `Access-Control-Allow-Origin: *`.
Разрешённые адреса задаются через `CORS_ORIGINS`. Для production используется
`https://desaichk.com`, для локальной разработки дополнительно разрешены
`localhost:5173` и `127.0.0.1:5173`.

## Что исправлено

Закрыт риск SEC-02 из этапа 5: сторонняя веб-страница больше не получает
CORS-доступ к API заявок.

## Как проверить

```bat
scripts\test.bat
scripts\release-check.bat
```

Или напрямую:

```bash
npm run test:security
npm run release:check
```

Тест запускает backend на временном порту и проверяет разрешённый и запрещённый
origin.

## Ограничения

- API пока не имеет авторизации и разграничения владельцев записей.
- Backend scraper использует временное JSON-хранилище.
- Внешние сайты поиска могут менять HTML или блокировать запросы.
- Планируется перенос хранения на PostgreSQL и добавление Redis-кэша.
